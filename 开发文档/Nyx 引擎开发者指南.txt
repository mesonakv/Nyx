四、三层架构
text
main.cpp                 ← 启动器
  ↓
MyGame                   ← 游戏逻辑（持有游戏对象，驱动主循环）
  ↓
NyxEngine                ← 引擎实例（持有所有子系统）
  ↓
[Core / Render / Scene / Editor / Resource / Physics / Input / Audio / World]
  ↓
[SDL2 / Vulkan / ImGui / glm]
数据流
text
Input → GameLogic → WorldState → Renderer
Input：InputSystem 采集原始事件

GameLogic：MyGame 读写 WorldState

WorldState：唯一的逻辑状态源

Renderer：只读 WorldState，通过 FrameData 接收

每帧流程
text
NyxEngine::BeginFrame(dt)
  ├── InputSystem::BeginFrame()         清空瞬时状态、裁剪事件历史
  └── AudioClock::Tick(dt)

while (SDL_PollEvent)
  ├── InputSystem::ProcessEvent()       采集输入
  ├── MyGame::ProcessEvent()            窗口事件
  └── ImGui_ImplSDL2_ProcessEvent()

MyGame::Update(dt)
  ├── 输入业务逻辑（F1、ESC）
  ├── 相机更新
  ├── 显示设置变更
  ├── 玩家更新（移动、跳跃、物理）
  └── 游戏逻辑更新

MyGame::Render()
  ├── LightingSystem::Update()
  ├── ImGuiManager::NewFrame() + EditorPanel::Draw()
  ├── DebugDraw：绘制物理/调试信息
  └── Renderer::DrawFrame(FrameData)

NyxEngine::EndFrame()
  └── InputSystem::EndFrame()
五、代码规范
5.1 命名
类型	规则	示例
类名	PascalCase	VulkanContext, MeshLoader
函数名	PascalCase	Initialize, DrawFrame
成员变量	snake_case + 尾下划线	currentFrame_, device_
局部变量	snake_case	frame_data, total_count
常量	k + PascalCase	kMaxDepth, kInvalidHandle
宏	NYX_ + 大写	NYX_LOG_INFO, NYX_NEW
命名空间	小写	nyx
5.2 格式
4 空格缩进（不用 tab）

大括号跟在同一行（K&R 风格）

一行不超过 120 字符

指针/引用符号贴着类型：Foo* ptr, const Foo& ref

cpp
void Foo::Bar() {
    if (condition) {
        DoSomething();
    } else {
        DoOther();
    }
}
5.3 类设计
数据成员默认 private

需要暴露的接口放 public

需要 public 数据成员时，注释说明原因

禁用拷贝（除非类真的是值语义）：MyClass(const MyClass&) = delete;

5.4 错误处理
不使用异常。三种处理方式：

cpp
// 1. 不可恢复 → Fatal + abort
NYX_LOG_FATAL("Cannot create device");

// 2. 可恢复 → 返回 false / nullptr
bool result = LoadFile(path);
if (!result) return;

// 3. 可恢复 + 需要细节 → 返回错误字符串
std::string err;
if (!LoadObj(path, mesh, &err)) {
    NYX_LOG_ERROR("Failed: %s", err.c_str());
}
5.5 注释
解释"为什么"，不解释"是什么"。

cpp
// ✅ 好
// 用 memmove 而不是 ring buffer，因为 600 个 float 的滑动开销
// 远小于维护环形的复杂度
memmove(...);

// ❌ 坏
// 把 buffer[i] 赋值给 buffer[i-1]
buffer[i] = buffer[i-1];

6.3 物理
cpp
#include "NyxEngine/Physics/PhysicsWorld.h"
#include "NyxEngine/Physics/Shapes/BoxShape.h"
#include "NyxEngine/Physics/Shapes/SphereShape.h"
#include "NyxEngine/Physics/Shapes/CapsuleShape.h"

PhysicsWorld& physics = engine.GetWorldState().physics;

// 创建形状
CollisionFilter filter = CollisionFilter::Make(
    PhysicsLayer::Player,
    PhysicsLayer::StaticGeo | PhysicsLayer::Target);

ShapeHandle handle = physics.CreateShape(
    std::make_unique<CapsuleShape>(0.4f, 0.45f),
    Transform{.position = {0, 1, 0}},
    filter);

// 更新位置
physics.UpdateTransform(handle, Transform{.position = newPos});

// 销毁
physics.DestroyShape(handle);

// 射线检测
RaycastHit hit = physics.Raycast(
    origin, direction, maxDistance,
    PhysicsLayer::StaticGeo);   // queryMask（单向：查属于这些层的形状）
if (hit.hit) {
    // hit.point, hit.normal, hit.distance, hit.shape
}

// 扫掠（防穿墙）
SweepHit sweep = physics.Sweep(
    shape, startTransform, direction, maxDistance,
    PhysicsLayer::StaticGeo);

// 重叠检测
std::vector<ShapeHandle> results;
physics.Overlap(shape, transform, PhysicsLayer::Target, results);

// 生成所有接触
std::vector<Contact> contacts;
physics.GenerateContacts(contacts);
碰撞过滤说明：

category：我属于哪些层

mask：我愿意和哪些层碰撞

CanCollideWith(other)：双向检查，用于碰撞对

查询：单向，(entry.filter.category & queryMask) != 0

九、常见坑
9.1 Windows.h 的宏
Windows.h 定义了一堆会干扰普通标识符的宏：

cpp
#define CreateDirectory CreateDirectoryA
#define min(a,b) (((a) < (b)) ? (a) : (b))
解决：include 之后立即 #undef：

cpp
#ifdef _WIN32
    #define WIN32_LEAN_AND_MEAN
    #include <Windows.h>
    #undef min
    #undef max
#endif
9.2 glm 需要 <cmath> 在前
MSVC 下 glm 的 .inl 有 using std::round;。如果 <cmath> 没先 include，会报错。

解决：include glm 之前先 include <cmath>，或直接 #include "NyxEngine/Core/NyxMath.h"。

9.3 不要用 Math.h 作文件名
Windows 大小写不敏感，你的 Math.h 会替换系统的 <math.h>。用 NyxMath.h。

9.4 显式列表必须更新
CMakeLists.txt 用的是显式源文件列表。新增 .cpp 后必须手动加进 CMakeLists.txt，否则链接错误。

9.5 相对路径
程序运行时，Shaders/xxx.spv 是相对于工作目录，不是可执行文件目录。

解决：始终从项目根目录运行，或用 FileSystem::GetExecutableDir() 拼绝对路径。

9.6 编码问题
项目强制 UTF-8（/utf-8 编译选项）。如果文件是 GBK 编码，会报 C4828。

解决：文件另存为 UTF-8。

9.7 vkDeviceWaitIdle 不要放热路径
会让 CPU 等 GPU 完全空闲，彻底消除并行。

✅ 正确：swapchain 重建、资源销毁时用

❌ 错误：每帧 DrawFrame 里用

9.8 std::vector 返回引用时注意生命周期
cpp
// ❌ 错误
const auto& pos1 = targets.GetAlivePositions();
const auto& scale1 = targets.GetAliveScales();
const auto& pos2 = targets.GetAlivePositions();  // pos1 已经变了！

// ✅ 正确
auto pos = targets.GetAlivePositions();  // 拷贝
9.9 中文输入法吞键
Windows 上中文输入法会截获键盘消息，导致游戏按键失效。

已解决：main.cpp 里调用 ImmDisableIME(-1)（线程级，不碰窗口）。

如果将来做聊天框：进入文本框前临时恢复 IME。

9.10 Raw Input 在编辑器模式下失效
编辑器模式下鼠标被释放，Raw Input 收不到消息。

已解决：InputSystem 自动回退到 SDL 通道。IsRawInputActive() 判断。

十一、遇到问题时
先看日志。引擎几乎所有操作都有日志。

看 Memory Stats。有泄漏说明某处没释放。

检查 Vulkan 返回值。关键调用已加检查。

最小化问题。把代码删到只剩出错的部分。

对比工作版本。git diff 看改了什么。
