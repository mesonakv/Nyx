1. 项目定位
Nyx 是一个专用 FPS 瞄准训练引擎，强调极低输入延迟、干净视觉、氛围光照和轻量破坏体验。
它不是通用引擎，而是为第一人称轻量动作体验量身定制的底层工具。

核心目标
输入延迟  5ms

中端 GPU 稳定 1000+ FPS

帧时间 P99  1.3ms

包体  50 MB

启动时间  1 秒

内存	 100 MB

帧时间标准差	 0.1 ms

当前结构的问题
main.cpp 承担过多职责，包含引擎初始化、主循环、游戏逻辑、ImGui 面板

没有统一的 NyxEngine 实例，Game 无法真正“调用引擎”

输入、光照、编辑器逻辑与 main 高度耦合

TargetManager 混合了渲染数据和游戏逻辑

3. 架构升级目标
3.1 引擎实例抽象
新增 NyxEngine 类，提供统一的引擎接口：

cpp
class NyxEngine {
public
    void Initialize(SDL_Window window, const DisplaySettings& settings);
    void Shutdown();

    VulkanContext& GetVulkanContext();
    Renderer& GetRenderer();
    InputSystem& GetInputSystem();
    Camera& GetMainCamera();
    LightingSystem& GetLightingSystem();

    void BeginFrame();
    void EndFrame();
};
3.2 游戏侧依赖引擎接口
cpp
class MyGame {
public
    void Initialize(NyxEngine& engine);
    void Update(float dt);
    void Render();
};
3.3 main.cpp 变为启动器
cpp
int main() {
    NyxEngine engine;
    engine.Initialize(window, settings);

    MyGame game;
    game.Initialize(engine);

    while (running) {
        engine.BeginFrame();
        game.Update(dt);
        game.Render();
        engine.EndFrame();
    }

    engine.Shutdown();
}

9. 旗舰技术：PrismSpectra
PrismSpectra 是 Nyx 的材质光学质感系统，包含菲涅尔、干净反射、清晰折射、色散与克制的粉蓝泛光。
适用于玻璃、珠光、金属、油墨等材质，是 Nyx 视觉语言的核心技术之一。

技术组件
菲涅尔：正面弱反射，斜角强反射

干净反射：反射天空和纯色几何体，不模糊

清晰折射：透过玻璃的目标依然锐利，仅轻微偏移

色散：高光边缘出现极淡的蓝紫粉偏移

微泛光：高光周围极克制的辉光

设计哲学
克制：粉蓝泛光只在高光边缘出现，且非常轻微

真实之上：物理正确，但更强调干净的视觉体验

可复用：同一套光学规则应用于玻璃、珠光、金属、油墨
