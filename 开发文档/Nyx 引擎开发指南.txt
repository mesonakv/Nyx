1. 环境搭建
1.1 必需工具
工具	版本	说明
Visual Studio	2022 或 2026	需要"使用 C++ 的桌面开发"工作负载
CMake	3.20+	命令行 cmake --version 能输出版本
Vulkan SDK	1.3+	提供 glslc 编译 shader
Git	任意	版本控制
1.2 验证环境
打开 PowerShell，逐条运行：

powershell
cmake --version           # 应有输出，如 "cmake version 4.4.3"
glslc --version           # 应有输出
$env:VULKAN_SDK           # 应指向 Vulkan SDK 目录
如果 glslc 找不到，把 %VULKAN_SDK%\Bin 加到系统 PATH。

1.3 项目路径
本文档假设项目在 D:\Dev\NyxEngine。如果你的路径不同，把命令里的路径替换。

2. 第一次编译运行
2.1 配置
第一次或修改了 CMakeLists.txt后：

powershell
cd D:\Dev\NyxEngine
cmake -S . -B build
2.2 编译
powershell
cmake --build build --config Release
2.3 编译着色器
powershell
cd D:\Dev\NyxEngine\Shaders
Get-ChildItem *.vert | ForEach-Object { glslc $_.FullName -o "$($_.FullName).spv" }
Get-ChildItem *.frag | ForEach-Object { glslc $_.FullName -o "$($_.FullName).spv" }
cd D:\Dev\NyxEngine
2.4 运行
powershell
.\build\Release\NyxEngine.exe
注意：工作目录必须是 D:\Dev\NyxEngine，因为程序里用的是相对路径 Shaders/xxx.spv。

2.5 日常循环
改代码后：

powershell
cmake --build build --config Release
.\build\Release\NyxEngine.exe
改 shader 后：

powershell
cd Shaders
glslc ball.frag -o ball.frag.spv   # 只重编改过的
cd ..
.\build\Release\NyxEngine.exe
新增 .cpp 文件后：必须重跑 cmake -S . -B build，因为 CMake 用的是 file(GLOB_RECURSE)，不会自动检测新文件。

5. 编写一个新游戏
5.1 最小可运行游戏
新建 Game/MyGame2.h：

cpp
#pragma once
#include <SDL.h>
#include "NyxEngine/NyxEngine.h"

class MyGame2 {
public:
    void Initialize(NyxEngine& engine, SDL_Window* window);
    void Shutdown();
    void Run();

private:
    NyxEngine* engine_ = nullptr;
    SDL_Window* window_ = nullptr;
    bool running_ = true;
    uint64_t lastFrameCounter_ = 0;
    uint64_t performanceFrequency_ = 0;
};
新建 Game/MyGame2.cpp：

cpp
#include "MyGame2.h"
#include "NyxEngine/Core/Logger.h"
#include "NyxEngine/Core/InputSystem.h"
#include "NyxEngine/Render/FrameData.h"
#include "NyxEngine/Scene/Camera.h"
#include <imgui.h>
#include <backends/imgui_impl_sdl2.h>

void MyGame2::Initialize(NyxEngine& engine, SDL_Window* window) {
    engine_ = &engine;
    window_ = window;
    performanceFrequency_ = SDL_GetPerformanceFrequency();
    lastFrameCounter_ = SDL_GetPerformanceCounter();
    NYX_LOG_INFO("MyGame2 initialized");
}

void MyGame2::Shutdown() {
    NYX_LOG_INFO("MyGame2 shutdown");
}

void MyGame2::Run() {
    while (running_) {
        uint64_t frameStart = SDL_GetPerformanceCounter();
        float dt = (float)((frameStart - lastFrameCounter_) * 1000.0 / performanceFrequency_) / 1000.0f;
        lastFrameCounter_ = frameStart;
        if (dt > 0.1f) dt = 0.1f;

        engine_->BeginFrame();

        // 事件
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            engine_->GetInput().ProcessEvent(event);
            ImGui_ImplSDL2_ProcessEvent(&event);
            if (event.type == SDL_QUIT) running_ = false;
        }

        // 输入
        InputSystem& input = engine_->GetInput();
        if (input.WasKeyPressed(SDL_SCANCODE_ESCAPE)) running_ = false;
        if (!input.IsMouseCaptured()) {
            input.SetMouseCaptured(true);
        }

        // 相机
        Camera& camera = engine_->GetCamera();
        camera.ProcessMouseDelta(input.GetMouseDeltaX(), input.GetMouseDeltaY());

        // 光照
        LightingData lighting = engine_->GetLighting().Update();

        // ImGui
        engine_->GetImGuiManager().NewFrame();
        ImGui::Begin("MyGame2");
        ImGui::Text("Hello, Terra!");
        ImGui::End();

        // 渲染
        std::vector<glm::vec3> positions;
        std::vector<float> scales;
        std::vector<Material> materials;

        VulkanContext& vk = engine_->GetVulkanContext();
        float aspect = (float)vk.swapchainExtent.width / (float)vk.swapchainExtent.height;

        FrameData frame;
        frame.view = camera.GetViewMatrix();
        frame.proj = camera.GetProjectionMatrix(aspect);
        frame.cameraPos = camera.position;
        frame.targetPositions = &positions;
        frame.targetScales = &scales;
        frame.targetMaterials = &materials;
        frame.lighting = lighting;
        frame.imgui = &engine_->GetImGuiManager();

        engine_->GetRenderer().DrawFrame(vk, frame);

        engine_->EndFrame();
    }
}
修改 main.cpp：

cpp
#include "Game/MyGame2.h"

// ...

MyGame2 game;
game.Initialize(engine, window);
game.Run();
game.Shutdown();
重跑 CMake：

powershell
cmake -S . -B build
cmake --build build --config Release
5.2 接入自己的游戏对象
游戏逻辑写在 MyGame2 里，通过 FrameData 提交给 Renderer。

7. 常见坑
7.1 Windows.h 的宏
Windows.h 定义了一堆会干扰普通标识符的宏：

cpp
#define CreateDirectory CreateDirectoryA
#define DeleteFile DeleteFileA
#define min(a,b) (((a) < (b)) ? (a) : (b))
#define max(a,b) (((a) > (b)) ? (a) : (b))
后果：你写 FileSystem::CreateDirectory，编译器看到的是 FileSystem::CreateDirectoryA。

解决：include Windows.h 之后，立即 #undef：

cpp
#ifdef _WIN32
    #define WIN32_LEAN_AND_MEAN
    #include <Windows.h>
    #undef CreateDirectory
    #undef DeleteFile
    #undef min
    #undef max
#endif
7.2 glm 需要 <cmath> 在前
MSVC 下 glm 的 .inl 里有 using std::round; 等语句。如果 <cmath> 没被先 include，会报 "round" 不是 "std" 的成员。

解决：include glm 之前先 include <cmath>，或者直接 #include "NyxEngine/Core/NyxMath.h"（它已经处理好了）。

7.3 不要用 Math.h 作文件名
Windows 大小写不敏感，你的 Math.h 会替换系统的 <math.h>。用 NyxMath.h 或 MathUtils.h。

7.4 CMake 不会自动检测新文件
项目用 file(GLOB_RECURSE)。新增 .cpp 后必须重跑：

powershell
cmake -S . -B build
否则会报"未解析的外部符号"。

7.5 相对路径
程序运行时，Shaders/xxx.spv 是相对于工作目录，不是可执行文件目录。

从 D:\Dev\NyxEngine 运行 → 工作目录是 D:\Dev\NyxEngine，Shaders/ 能找到

双击 build\Release\NyxEngine.exe → 工作目录是 build\Release，找不到 Shaders/

解决：始终从项目根目录运行，或用 FileSystem::GetExecutableDir() 拼绝对路径。

7.6 编码问题
项目强制 UTF-8（/utf-8 编译选项）。如果某个文件是 GBK 编码，会报 C4828。

解决：把文件另存为 UTF-8（VS 里"另存为" → 编码选"UTF-8 带签名"）。

7.7 vkDeviceWaitIdle 不要放热路径
它会让 CPU 等 GPU 完全空闲，彻底消除并行。

✅ 正确：swapchain 重建、资源销毁时用

❌ 错误：每帧 DrawFrame 里用

7.8 std::vector 返回引用时要注意生命周期
TargetManager::GetAlivePositions() 返回 const std::vector&。不要存这个引用，因为下一次调用会重建它。

cpp
// ❌ 错误
const auto& pos1 = targets.GetAlivePositions();
const auto& scale1 = targets.GetAliveScales();
const auto& pos2 = targets.GetAlivePositions();  // pos1 已经变了！

// ✅ 正确：立即使用，或拷贝
auto pos = targets.GetAlivePositions();  // 拷贝
8. 调试技巧
8.1 日志分级
Debug 构建下，NYX_LOG_TRACE 和 NYX_LOG_DEBUG 会输出。Release 下不输出。

如果要在 Release 下看更多日志，改 main.cpp：

cpp
LoggerConfig logConfig;
logConfig.minLevel = LogLevel::Debug;   // 改成 Debug
8.2 内存泄漏检测
程序退出时会打印 Memory Stats。如果有泄漏：

text
[INFO ] Memory: 3 allocations still live at shutdown
[INFO ]   Leak: 256 bytes at Renderer.cpp:123 (tag=Render)
[INFO ]   Leak: 64 bytes at Material.cpp:45 (tag=Material)
根据文件:行号定位。

8.3 Vulkan 验证层
当前未启用。如果要查 Vulkan 错误，在 VulkanContext::Initialize 里加：

cpp
const char* validationLayers[] = { "VK_LAYER_KHRONOS_validation" };
createInfo.enabledLayerCount = 1;
createInfo.ppEnabledLayerNames = validationLayers;
需要 Vulkan SDK 的验证层 DLL 在 PATH 里。

8.4 性能测量
编辑器 F1 → Performance 面板，看：

Avg：平均帧时间

P99：99% 分位的帧时间

Worst 1%：最差 1% 的平均

StdDev：标准差

好的数值：StdDev < 0.1ms，P99 < 1.5×Avg

8.5 查看控制台输出
从 PowerShell 运行程序时，日志会实时显示。

如果程序是从 VS 里启动的，日志出现在"输出"窗口（VS 菜单：视图 → 输出）。

9. 代码规范
9.1 命名
类型	规则	示例
类名	PascalCase	VulkanContext, MeshLoader
函数名	PascalCase	Initialize, DrawFrame
成员变量	snake_case + 尾下划线	currentFrame_, device_
局部变量	snake_case	frame_data, total_count
常量	k + PascalCase	kMaxDepth, kInvalidHandle
宏	NYX_ + 大写	NYX_LOG_INFO, NYX_NEW
命名空间	小写	nyx
9.2 文件组织
头文件用 #pragma once

头文件先 include 自己的依赖，再 include 项目内的

.cpp 先 include 自己的头文件，再 include 其他

cpp
// Foo.cpp
#include "Foo.h"          // 自己的头文件
#include "Logger.h"       // 项目内
#include <vector>         // 标准库
#include <Windows.h>      // 系统
9.3 类设计
数据成员默认 private

需要暴露的接口放 public

如果确实需要 public 数据成员（像 VulkanContext），注释说明为什么

禁用拷贝（除非类真的是值语义）：MyClass(const MyClass&) = delete;

9.4 注释
解释"为什么"，不解释"是什么"

复杂的逻辑必须注释

简单的 getter/setter 不注释

文件头写一句话总结职责

cpp
// ✅ 好：解释为什么
// 用 memmove 而不是 ring buffer，因为 600 个 float 的滑动开销
// 远小于维护环形的复杂度
memmove(...);

// ❌ 坏：重复代码
// 把 buffer[i] 赋值给 buffer[i-1]
buffer[i] = buffer[i-1];
9.5 错误处理
不用异常。用以下三种：

cpp
// 1. 不可恢复错误 → Fatal + abort
NYX_LOG_FATAL("Cannot create device");
// 不会走到这里

// 2. 可恢复错误 → 返回 false / nullptr
bool result = LoadFile(path);
if (!result) return;

// 3. 可恢复错误 + 需要细节 → 返回错误字符串
std::string err;
if (!LoadObj(path, mesh, &err)) {
    NYX_LOG_ERROR("Failed: %s", err.c_str());
}
9.6 格式
4 空格缩进（不用 tab）

大括号独占一行（Allman 风格）

一行不超过 120 字符

指针/引用符号贴着类型：Foo* ptr, const Foo& ref

cpp
void Foo::Bar()

    {

11. 遇到问题时
先看日志。引擎几乎所有操作都有日志。

看 Memory Stats。有泄漏说明某处没释放。

检查 Vulkan 返回值。Renderer 和 VulkanContext 里已检查关键调用。

最小化问题。把代码删到只剩出错的部分。

对比工作版本。git diff 看改了什么。
