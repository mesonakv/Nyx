琉光幻彩（PrismSpectra）
Nyx 引擎材质光学质感系统
版本 1.0.0（设计文档）
最后更新：2026-09-13

1. 一句话定义
琉光幻彩是一套为 Nyx 引擎量身定制的材质光学系统。它不追求物理正确，而追求光学正确——在受控的场景中，用克制的艺术判断和极低的实时开销，让金属看起来像金属、玻璃看起来像玻璃、油墨看起来像油墨。

2. 名字的由来
Prism——棱镜。白光穿过棱镜后分解为光谱，这是光的色散。琉光幻彩里最重要的一层视觉语言——高光边缘极淡的蓝紫粉偏移——正是来源于此。

Spectra——光谱。不是单一的颜色，而是一组随角度、距离、材质变化的连续色。

琉光幻彩——中文名。琉（琉璃的质地）、光（光学）、幻（超越现实但不脱离现实）、彩（色彩）。四个字概括了它的四个层次：材质质感、光学规律、艺术加工、色彩表达。

3. 为什么需要它
3.1 现有方案的不足
在实时渲染领域，玻璃、金属、珠光这类"高光学质感"材质，一直没有让人完全满意的解决方案。

通用引擎的取舍

方案	代表	不足
屏幕空间反射	UE / Unity	屏幕外信息缺失，边缘发闷
屏幕空间折射	UE	大平面失真，无厚度感
半透明排序	所有通用引擎	重叠时闪烁、错乱
光照探针	各种	环境是模糊的，缺乏清晰感
离线渲染的代价

路径追踪、光谱渲染、薄片干涉，这些离线渲染器的标准配置，在实时渲染中的成本高到无法承受。一次完整的路径追踪，可能需要几毫秒到几十毫秒一帧。

结果：UE 的玻璃常常"一般"，Unity 的玻璃常常"塑料感"，独立引擎的玻璃常常"糊"。这不是技术不行，是通用引擎必须为所有场景做妥协。

3.2 Nyx 的独特位置
Nyx 是专用引擎，不追求"所有场景都能用"。它只服务两个应用：

训练器：一个受控的室内场景，天空是程序化生成的

Terra：一个球体地球，但核心体验是"看世界"，不是"捏材质"

这两个应用有一个共同点：反射源可以被简化、被控制、被完全掌握。

琉光幻彩正是基于这个判断设计的。它利用"我知道反射源是什么"这个先验知识，用极低的成本换取极高的视觉质量。

4. 五个技术组件
琉光幻彩由五个视觉层次构成，每一层都可以独立开关、独立调参。

4.1 菲涅尔
视觉描述

一个球体，从正面看是哑光的，从斜角看是反光的。这不是模糊的渐变，而是一个由中心到边缘逐渐增强的反射亮环。

物理依据

菲涅尔方程：光在两种介质交界面的反射率，取决于入射角。垂直入射时反射率最低，掠射时反射率趋近 100%。

Nyx 实现

采用 Schlick 近似：

text
F = F0 + (1 - F0) * pow(1 - dot(N, V), 5)
其中 F0 由 metallic 推导，但允许 fresnelStrength 覆盖。

视觉目标：让材质有"体积感"。玻璃球和塑料球的差别，很大程度上就是菲涅尔。

4.2 干净反射
视觉描述

球体表面映出天空。天空是蓝色的，球体反射的就是蓝色。天空变橙色，反射也变橙色。太阳移动时，球体表面有一个清晰的光斑跟着移动。

反射是清晰的——能看到天空中太阳的轮廓，不是糊成一团。

Nyx 实现

从程序化天空采样：

text
vec3 R = reflect(-V, N);
vec3 envColor = SampleSky(R);
SampleSky 使用和天空着色器相同的天空颜色渐变。

和通用方案的差别：没有 cubemap、没有 SSR、没有 Lumen。反射源就是一个已经算好的天空梯度。零额外开销。

视觉目标：让反射"清晰"，让"金属像金属"。

4.3 清晰折射
视觉描述

透过玻璃看东西，东西是锐利的，只是位置有轻微偏移。玻璃不模糊后面的物体——这是玻璃和磨砂玻璃的区别。

Nyx 实现

屏幕空间折射：在 shader 里对背景纹理做 UV 偏移。

text
vec2 offset = refractDir.xy * refractionStrength;
vec3 refractedColor = texture(background, screenUV + offset).rgb;
关键约束：offset 必须很小。偏移量大了，就会失真、模糊。

视觉目标：玻璃"透明"，但"不透明得像空气"。它有自己的存在感，但不遮挡世界。

4.4 色散
视觉描述

玻璃球的边缘，有一丝淡淡的蓝紫粉。不仔细看看不出来，但一旦发现，会觉得"对了"。

物理依据

不同波长的光，在介质中的折射率不同。红光偏折小，蓝光偏折大。白光穿过玻璃后分解为彩虹——这就是棱镜效应。

Nyx 实现

对 RGB 三个通道用略微不同的折射率采样：

text
float etaR = 1.0 / (ior - dispersion);
float etaG = 1.0 / ior;
float etaB = 1.0 / (ior + dispersion);

vec3 refrR = refract(-V, N, etaR);
vec3 refrG = refract(-V, N, etaG);
vec3 refrB = refract(-V, N, etaB);

vec3 color;
color.r = SampleSky(refrR).r;
color.g = SampleSky(refrG).g;
color.b = SampleSky(refrB).b;
视觉目标：给玻璃"生命"。一点色散，就是"真玻璃"和"CG 玻璃"的差别。

4.5 微泛光
视觉描述

高光点周围有一圈极小的光晕。不是游戏里那种夸张的 bloom，更像相机镜头上的柔和光斑。

Nyx 实现

独立的 bloom 后处理：

从渲染结果提取高光区域（luminance > threshold）

两趟高斯模糊（水平 + 垂直）

叠回原图，权重很低

关键约束：bloom 的半径要小（几个像素），强度要低（0.1~0.3）。

视觉目标：让高光"温和"，让画面"有呼吸感"，但不"油腻"。

5. 设计哲学
5.1 克制
琉光幻彩最重要的原则是克制。

粉蓝泛光只在高光边缘出现，且非常轻微

色散只在玻璃边缘出现，且非常淡

反射清晰，不糊

泛光很小，不夸张

这和其他引擎追求"华丽"的方向完全相反。琉光幻彩要的是安静的高级感——你第一眼不会觉得"哇好炫"，但你会觉得"这个画面很舒服"。

5.2 真实之上
琉光幻彩物理正确，但不完全物理。

比如色散：真实的色散是连续的，琉光幻彩只用 RGB 三个采样。真实的色散对每个角度都不同，琉光幻彩只在边缘明显。

这些简化不是偷懒，是艺术选择。用户看到的不是"物理"，是"感觉"。

5.3 可复用
同一套光学规则，应用在玻璃、珠光、金属、油墨四种材质上。

玻璃：菲涅尔 + 干净反射 + 清晰折射 + 色散

珠光：菲涅尔 + 干净反射 + 微弱色散

金属：菲涅尔 + 干净反射 + 无折射

油墨：菲涅尔 + 极弱反射 + 强烈色散

参数不同，规则相同。这是琉光幻彩作为一个"系统"而非"效果"的关键。

5.4 专用而非通用
琉光幻彩不试图成为任何东西。

它不用于户外场景（户外反射源太复杂）

它不用于粒子（粒子需要不同的光学模型）

它不用于大规模地形（地形是漫反射主导）

它只用于需要光学质感的中小物体——球体、玻璃、金属表面、水面。

6. 和其他方案的对比
维度	UE / Unity	离线渲染（Cycles / Octane）	琉光幻彩
反射源	场景捕获 / Lumen	完整光追	程序化天空
菲涅尔	PBR 参数推导	物理精确	混合（推导 + 覆盖）
色散	需自定义 / 昂贵	物理精确	屏幕空间 RGB 分离

性能开销	中等 ~ 高	极高	极低
适用场景	通用	静态渲染	受控实时场景
视觉目标	可用	真实	光学正确
琉光幻彩不是 UE 的替代品。它是 Nyx 的专属。

7. 参数空间
7.1 材质参数
cpp
struct Material {
    // 基础 PBR
    glm::vec4 color;           // 基础色
    float metallic;            // 金属度 0~1
    float roughness;           // 粗糙度 0~1
    float emissive_strength;   // 自发光强度
    float opacity;             // 不透明度

    // 琉光幻彩
    float fresnelStrength;     // 菲涅尔强度 0~1（0 = 自动推导）
    float dispersion;          // 色散强度 0~0.1
    float refractionStrength;  // 折射强度 0~1
    float bloomTint;           // 泛光色调（0 = 无泛光，1 = 粉蓝）
};

8. 实现路线
第一步：菲涅尔 + 干净反射
Material 加 fresnelStrength

ObjectPushData 加一个 vec4（fresnel, dispersion, bloomTint, pad）

ball.frag 实现菲涅尔 + 环境采样

编辑器加 slider

产出：金属和玻璃的质感立刻出来。

第二步：清晰折射 + 色散
ball.frag 加屏幕空间折射

RGB 三通道不同折射率

编辑器加 slider

产出：玻璃边缘有淡淡的蓝紫。

第三步：微泛光
新建 BloomPass 类

两趟高斯模糊 + 合成

RenderConfig 加 bloom 参数

产出：高光有克制的光晕。

10. 琉光幻彩不是什么
明确它的边界，比说它是什么更重要。

它不是 PBR。PBR 是它的一部分，不是它的全部。PBR 描述材质如何反射光，琉光幻彩描述材质看起来像什么。

它不是后处理。它大部分工作在 shader 里，和材质绑定。

它不是物理正确。它是光学正确——物理规律服务视觉目标，而不是相反。

它不是通用方案。它不适合所有场景，只适合 Nyx 的场景。

它不是一款产品。它是 Nyx 引擎的一部分，不会单独发布。

11. 一句话收尾
琉光幻彩不是把光照算得更准，而是把"光学质感"这件事，在正确的地方、用正确的方法、以正确的代价做出来。
